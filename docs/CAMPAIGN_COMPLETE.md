# GAME OVERVIEW RECAP

## What is Mindscape?

**Mindscape** is a gamified productivity and self-improvement application disguised as an isometric RPG. Players take on the role of **Agent Goacto**, a young alien on a 50-year intergalactic cruise who discovers an ancient program called "Human Potential" that lets them connect with and help a human on Earth achieve their potential.

The brilliance lies in the meta-narrative: the "human" Goacto is helping is actually the player themselves. Every focus session, habit completed, and journal entry the player makes in real life is framed as Goacto assisting their chosen human, creating an emotional distance that makes self-improvement feel like adventure rather than obligation.

## Core Philosophy: GOACTO
**G**rowing **O**urselves **A**nd **C**ontributing **T**o **O**thers

# COMPLETE CAMPAIGN STRUCTURE

## Overview

The campaign is divided into **4 Acts**, each containing **4-5 Chapters**. Each chapter has multiple **Parts** (scenes/sequences) and specific **Unlocks** tied to player actions.

```
ACT I: CONNECTION (Chapters 1-3)
  └── Discovery, first contact, foundation building

ACT II: GROWTH (Chapters 4-7)
  └── Expansion, more aspects, first challenges

ACT III: CRISIS (Chapters 8-11)
  └── Dark night of the soul, major resistance battles

ACT IV: MASTERY (Chapters 12-15)
  └── Integration, teaching others, completion

EPILOGUE: CONTINUATION
  └── Post-game content, endless growth
```

## Implementation: Bedroom State Management

### GameManager.player_data Extensions

```gdscript
var player_data = {
    # ... existing fields ...

    # Bedroom progression
    "bedroom_stage": 1,  # 1-4 based on installed items
    "bedroom_items_installed": [],  # ["mindscape_console", "wardrobe", "mirror", "archive"]
    "pending_installations": [],  # Items collected but not yet installed

    # Ship access
    "ship_rooms_unlocked": ["bedroom"],  # Expands as campaign progresses
}
```

### Bedroom Scene Integration

```gdscript
# bedroom.gd - Check installed items on load
func _ready():
    _load_bedroom_state()
    _show_installed_items()
    _check_pending_installations()

func _show_installed_items():
    var installed = GameManager.player_data.get("bedroom_items_installed", [])

    # Hide all optional items by default
    $MindscapeConsole.visible = "mindscape_console" in installed
    $WardrobeCloset.visible = "wardrobe" in installed
    $HolographicMirror.visible = "mirror" in installed
    $DataArchive.visible = "archive" in installed

func _install_item(item_id: String):
    var installed = GameManager.player_data.get("bedroom_items_installed", [])
    if item_id not in installed:
        installed.append(item_id)
        GameManager.player_data["bedroom_items_installed"] = installed
        _update_bedroom_stage()
        _play_installation_animation(item_id)
        SaveManager.save_game()
```
